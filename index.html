המחקר והשיטה

המעבדה מחברת מבט כולל לקריאת מקור: צבירת ספירות, נרמול, בדיקת רצפים ופתיחת העדויות. זו התאמה של עקרונות מסקירת הקריאה הקרובה והרחוקה, Voyant ו־ViTA לנתוני הפסוקים שבמאגר.

Jänicke et al. — On Close and Distant Reading · Voyant — Tools · Oxford — ViTA · עשר השאלות והמדדים

יחידת ההשוואה היא JSON אחד. קשרים בתרשים אינם מוכיחים העתקה, כיוון השפעה או תיארוך. ציטוטים חופפים וזיהויים קצרים ניתנים לבדיקה במקור.

כיסוי הנתונים

דוח קליטת קבצים · דוח כיסוי המקורות · הוראות הפעלה ובנייה

הוספת כל הזוהר והמדרשים

כל יחידות שלושת קובצי ה־ZIP שסופקו נקלטו: 3,093 מהזוהר, 1,073 מתנחומא בובר ו־901 מתנחומא. נוספו שבע יחידות תנחומא שכבר נקלטו מהתיקייה המקורית. דוח הכיסוי מפרט את המקורות. להוספת ספרים אפשר להזין תיקיות או קובצי ZIP נוספים באותה פקודה.

python tools/build_corpus.py --input full-folder.zip

הכלי קורא את כל קובצי ה־JSON, מזהה חיבורים לפי מזהי המקור, מאחד כפילויות, יוצר אינדקסים וטקסטים מחולקים לקבצים קטנים, ומפיק דוח שגיאות. קליטת כל קובצי הקלט אינה הוכחה לשלמות הביבליוגרפית של מהדורה.

הוספת ספר נוסף

python tools/build_corpus.py --input new-book.zip --book new-book --title "שם הספר"

החיבור יתווסף לתפריטי הבחירה ללא שינוי בקוד. נדרש JSON עם טקסט וזיהויי פסוקים במבנה המקור שסופק; טקסט גולמי ללא זיהויים מחייב שלב חילוץ נפרד. מבנה הקלט מפורט בהוראות ההפעלה.

איך החיפוש עובד

לכל פסוק נשמר אינדקס של היחידות שבהן הוא מופיע. לפני השוואת רצפים נבחרות רק יחידות שיש בהן מספיק הופעות משותפות. לאחר מכן מחושב הרצף המרבי לפי השיטה שבחרתם. לכל חיבור קובצי אינדקס נפרדים; הטקסטים המלאים אינם חלק מהם. החישוב נעשה ברקע, והטקסטים נטענים רק בפתיחת תוצאה. המטמון מוגבל ואפשר לעצור חיפוש.

במצב מסודר מוצג פתרון מרבי נציג לכל זוג יחידות; ייתכנו חלופות באותו אורך. ללא סדר מחושב חיתוך של אוספי הפסוקים עם ריבוי הופעות. התוצאות אינן מונות את כל תתי־הרצפים. ההשוואה מתבצעת בתוך גבולות קובצי המקור.

איתור יחידה לפי מילים דורש שכל המילים יופיעו באותה יחידה, ללא ניקוד או סימני פיסוק. הוא אינו דורש סמיכות ואינו מחפש לפי שורש או הטיות. האיתור מצמצם את רשימת היחידות בספר שנבחר; לאחר מכן מסמנים דרשות להשוואה עם הספרים האחרים; כל דרשה נבדקת בנפרד.

הטקסט המוצג הוא הטקסט שבקובצי החילוץ, לא הורדה חדשה של מהדורת ספריא. ההדגשות נשענות על מיקומי המילים; אי־התאמות מוצגות בטקסט. זיהויים קצרים אינם תיקונים מאומתים. המקורות המקוריים אינם מתוקנים אוטומטית.

שמירה ופרסום

שמירת חיפוש מורידה את ההגדרות ואת מזהי התוצאות בלבד, ללא העתקת כל הספרייה. הטעינה מתאימה לאותה גרסת נתונים. קובץ המחקר אינו גיבוי של הטקסטים.

האתר מתאים ל־GitHub Pages. בפתיחה מקומית נדרש שרת קבצים: הפעילו START_WINDOWS.bat או הריצו python tools/serve.py. פתיחת index.html ישירות אינה נתמכת בגרסה זו, כדי לאפשר טעינה לפי דרישה.
