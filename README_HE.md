# זוהר מול המדרשים — גרסה 7.1

מערכת סטטית להשוואת שרשראות פסוקים, לקריאת יחידות מקור בטורים ולבחינת דמיון בין חיבורים. הקורפוס כולל 10,763 יחידות מקור ו־178,808 רשומות זיהוי פסוקים: 3,093 יחידות זוהר ו־15 מדרשים. אלו כל הקבצים התקינים שנקלטו; אין בכך אישור לשלמות מהדורה או לכך שכל קובץ JSON הוא דרשה שלמה.

## הפעלה

ב־Windows הפעילו `START_WINDOWS.bat`, או הריצו:

```sh
python tools/serve.py
```

פתחו את הכתובת שהשרת מדפיס. נדרש Python 3 לשרת המקומי בלבד. לפרסום ב־GitHub Pages מעלים את `index.html`, התיקיות `assets` ו־`data`, ואת קובצי התיעוד. אין לפתוח את `index.html` ישירות כקובץ. הדפדפן צריך לתמוך ב־Web Workers וב־`DecompressionStream(gzip)`.

## הממשק

- **השוואה** היא סביבת הקריאה הראשית: יחידות זוהר מול המדרשים שנבחרו, טקסט מלא, הדגשת פסוקים, רכבת צבעונית, חיפוש ודפדוף.
- **מבט כללי** פותח בזוהר מול כל החיבורים שנבחרו, במפת חום שקל לקרוא בה את הדמיון, מספר הזוגות והכיסוי בכל צד. בהמשך מוצגות עד 40 דוגמאות מדורגות לכתיבה ולקריאה, לפי אורך השרשרת ובתיעדוף שרשראות שחוצות ספרי מקרא. אפשר גם להשוות חלקים בתוך אותו חיבור. בוחרים מקור בסיס או מפת זוגות, קובעים סף אורך, סדר, מרחב מקראי וסינון פסוקים עוקבים, ומקבלים תרשים שאפשר לפתוח ממנו דוגמה בטקסט מלא.
- **ניתוח יחידה** מנתח יחידת בסיס ואת המקבילות שלה; **מעבדה** מכילה את ניתוחי הקורפוס והניסויים המחקריים.
- בחירת המקורות כוללת חיפוש לפי שם, קבוצות לפי תפקיד מחקרי, קיצורי דרך לבחירת שני נוסחי התנחומא או כל המקורות, ומונה יחידות. רשימות הפרשות מסודרות לפי סדר הפרשות המקראי; כותרות שאינן פרשות נשמרות לפי סדר המקור.

כל JSON נשאר יחידת החישוב. המערכת אינה מחברת דרשות סמוכות באופן מלאכותי. נתוני האינדקס נטענים לפי הצורך; הטקסטים המלאים נטענים רק כשפותחים יחידה או דוגמה. הנתונים דחוסים ב־gzip; ארכיוני ZIP ומסד הבנייה אינם חלק מפרסום האתר.

## קורפוס מקורות

המקורות החדשים שנקלטו בגרסה זו הם ספרי במדבר, ספרי דברים, מדרש ילמדנו / ילקוט תלמוד תורה, מכילתא דרבי ישמעאל, מכילתא דרבי שמעון בן יוחאי ואגדת בראשית. שני קובצי ילקוט תלמוד תורה שהועלו היו זהים בתוכנם ונקלטו פעם אחת.

חלוקת הזוהר נשמרת לפי כותרות המקור וכוללת גם חלקים מיוחדים המסומנים בקלט. אין להסיק מהכותרות לבדן שהן תואמות לחלוקה מחקרית של חלקי הזוהר. גבולות היחידות הם גבולות קובצי המקור, לא גבולות דרשה שאומתו.

## מבט כללי ומדד הדמיון

במצב ״מקור אחד מול אחרים״ אפשר לבדוק את הזוהר מול התנחומא ושאר המדרשים, או לבחור את התנחומא כעוגן ולהשוות מקורות אחרים אליו. מצב ״מפת כל הזוגות״ מחשב זוגות מתוך עד שמונה חיבורים בכל הרצה. מצב ״השוואת חלקים בחיבור״ בודק, למשל, שתי פרשות זוהר זו מול זו.

לכל זוג מוצגים מספר זוגות היחידות שמצאו התאמה, שיעור היחידות המתאימות מכל צד, ודמיון משוקלל — ממוצע הרמוני של שני שיעורי הכיסוי. המדד מאפשר להשוות חיבורים בגדלים שונים, אבל אינו הוכחה לתלות, להשפעה או למקור ישיר. לחיצה על תוצאה פותחת דוגמה מייצגת, עם הטקסטים והפסוקים המסומנים בצבע.

הסינון ״הסתר טיפול רצוף בפסוקים עוקבים״ מופעל כברירת מחדל במבט הכללי ובחיפוש. הוא מסיר רק התאמות שמורכבות מרצף קדימה של פסוקים שונים באותו ספר ובאותו פרק, בשני המקורות, לפי הגדרה מבנית שמרנית. אין בו זיהוי של קרבה נושאית.

## ניסויים וקריאה מחקרית

המעבדה מאפשרת להריץ ניסויים על כלל הקורפוס או על בחירה מוגדרת. לאחר הוספת מקורות, ניסוי הבסיס הישן אינו משויך לגרסה זו; יש להריץ חישוב חדש כדי לקבל תוצאות ניסוי מעודכנות. התיעוד ב־[RESEARCH_HE.md](RESEARCH_HE.md) מפרט את יחידת המדידה, המדדים ומגבלות ההסקה.

סימוני מידע קטנים מסבירים את הבוררים, המדדים והתרשימים. הסברים דומים מאוחדים באותו אזור. תיוגי מקרים ותיקי מחקר נשמרים בדפדפן, ולכן יש לייצא אותם לגיבוי.

## הוספת מקורות

```sh
python tools/build_corpus.py --input additional-book.zip
python tools/compact_data.py
```

הבנייה מזהה מקור לפי `location` ומוסיפה את כל קובצי ה־JSON התקינים. הקלט צריך להכיל טקסט, מיקומי מילים וזיהויי פסוקים. טקסט ללא זיהויים מחייב שלב חילוץ נפרד. אחרי בנייה יש לעבור על `data/build-report.json`, `data/evidence-audit.json` ועל הספירות במניפסט. אין להעלות לאתר את קובצי המקור או את תיקיית `.build`.

## בדיקות

קובצי הבדיקה נשמרו בתיקיית `tests`. בבניית גרסה זו לא הורצו בדיקות האפליקציה האוטומטיות ולא הושלמה בדיקה חזותית בדפדפן. נתוני הקליטה וסיכום הדחיסה מוצגים בדוחות `data/build-report.json` ו־`data/size-report.json`; ראו [BUGCHECK_HE.md](BUGCHECK_HE.md) למצב האימות המדויק.
