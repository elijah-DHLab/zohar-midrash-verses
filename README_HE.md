# זוהר מול המדרשים — 6.3

מערכת סטטית לחיפוש שרשרות פסוקים ולקריאה פרשנית בטורים. האוסף נשמר בשלמותו: 9,217 קובצי מקור, מהם 3,093 בזוהר ו־6,124 בתשעה מדרשים. 153,459 רשומות זיהוי מקוריות נשמרו; אלה אינן 153,459 ציטוטים עצמאיים, משום שיש גם חלופות לאותן מילים.

## מתחילים

ב־Windows הפעילו START_WINDOWS.bat, או הריצו:

```
python tools/serve.py
```

פתחו את הכתובת המודפסת. נדרש Python 3 לשרת המקומי בלבד. לפתיחה ב־GitHub Pages העלו את תוכן התיקייה: index.html, assets ו־data באותה רמה. אין לפתוח index.html כקובץ מקומי. נדרש דפדפן עדכני עם Web Workers ו־DecompressionStream(gzip). אין שירות בתשלום, התקנת חבילות, API או שרת חישוב.

## הקריאה נשארה במרכז

ברירת המחדל: כל יחידות הזוהר, שני התנחומות, ללא סדר, לפחות שתי הופעות משותפות, טקסט מלא, ״כל הפסוקים ביחידה״ כבוי. כל JSON הוא יחידת חישוב עצמאית; אין חיבור מלאכותי בין יחידות. בחירה מרובה, בחר הכול, חיפוש מילים/יחידות/פסוקים, החלפת מדרש בטור, בחירת יחידה מקבילה, שניים או שלושה טורי קריאה, רכבת צבעונית לחיצה, איחוד חזרות, הרחבת הקשר, שמירת חיפוש, CSV והדפסה נשמרו.

כאשר לאותן מילים כמה ייחוסים, מופיע קרון אחד עם סימן ?. אלו חלופות לזיהוי אחד. אפשרויות חיפוש מאפשרות להוציא ייחוסים חלופיים וחפיפות, או לחזור לספירת רשומות המקור לצורך ביקורת. הסינון אינו מוחק את טקסט המקור. מספורי הקרונות עשויים לכלול פערים כאשר חלק מההופעות אינן מוצגות.

## הסברים בממשק

סימון i קטן מעוגן ליד בוררים, כותרות, מדדים ותרשימים, בלי פריט נפרד שיכול לרדת לשורה משלו. הסברים זהים באותה קבוצה מאוחדים לסימון אחד; בקבוצות בחירה ההסבר מוצמד לכותרת הקבוצה. מעבר עכבר או מיקוד במקלדת מציגים הסבר קצר. לחיצה פותחת חלונית שנשארת זמינה לקריאה, גם בטלפון; Escape, לחיצה מחוץ לחלונית או כפתור הסגירה סוגרים אותה. העזרה מופיעה גם לאחר מעבר בין מבטים דינמיים במעבדה, ואינה משנה את המסננים או את הנתונים.

## הניסויים החדשים

לחצו על ״ניסויים״ ליד ההשוואה, או מעבדה ← ניסויים וממצאים. בפתיחה נטען לפי דרישה ניסוי בסיס מחושב מראש: כל הזוהר מול תשעת המדרשים, סף שלוש הופעות, אותו סדר עם דילוגים, כיווץ חזרות. מספרי הניסוי והגדרותיו מוצגים בנפרד מן החיפוש הפתוח. הם אינם מוצגים כאילו חושבו על כל בחירה חדשה.

אפשר להריץ ניסוי חדש על יחידות החיפוש האחרון, היחידה המוצגת או כלל הזוהר. בחירת המדרשים בניסוי נפרדת מבחירת טורי הקריאה. יש קיצורי דרך לשני התנחומות, לחמשת מקורות ההשוואה, או לכל המדרשים. החישוב פועל ב־Worker נפרד וניתן לעצירה.

שבע תצוגות:

1. תוצאות ניסויים: מעברים שנצפו מול ערבובי סדר, p ו־q; והשוואה באוכלוסיות מדרש בעלות היקף והרכב תואמים בקירוב.
2. מפת מקבילות: כל יחידות הזוהר בהיקף שנבחר מול כל מקור, עם פתיחת תא לטקסטים.
3. משפך: רשומות מקור ← הופעות מאוחדות ← זיהויים יחידים וללא חפיפות ← פסוקים שונים ← הוצאת פתיחה ← מעבר ישיר שאינו חזרה או הפסוק הבא.
4. מקרים לקריאה: עמידה בסינון, נדירות מעברים ותיוג פרשני ידני מתיקי המקרה.
5. נדפס מול בובר: בחירת שתי יחידות מול אותה יחידת זוהר, פתיחת שלושה טורים וסימון אימות ידני של המקבילות.
6. בין הפסוקים: הטקסט בין מעברים משותפים, עם כל הופעה חוזרת בנפרד.
7. יציבות: חישוב מחדש של ההשוואה המלאה בתנאים שונים, גם לפני הרצת ניסוי כולל.

שמונה מבטי המחקר הקודמים, שמונת תרשימי המבט המשווה ועשרת תרשימי האוסף נשמרו. תיוג ותיקי מקרה נשמרים בדפדפן; ייצאו אותם לגיבוי. תוצאות ניסוי ניתנות לייצוא כ־JSON עם השיטה, הזרע, המזהים, כל הזוגות וטווחי הערבוב. תוצאות ניסוי חדש אינן נשמרות לאחר סגירת הדף ללא ייצוא.

## מה אפשר להסיק

הפרטים ב־RESEARCH_HE.md. הניסויים כעת ממשיים, אך חקרניים. ערבוב הסדר בודק חריגה ממודל מוגדר, לא מקור ישיר. התאמת האוכלוסיות משתמשת בספר התורה הדומיננטי כקירוב להקשר, ולא בפרשה שאומתה. גודל קטן של קבוצת הביקורת מודגש. אין הסקה אוטומטית של פירוש, עצמאות מסורות, כיוון השפעה או תיארוך. שמות הקלט אינם ייחוס לחטיבות לפי מרוז. גבולות JSON אינם בהכרח גבולות דרשות.

## הוספת חיבור

```
python tools/build_corpus.py --input additional-book.zip
python tools/compact_data.py
```

הפקודה השנייה דוחסת ומוסיפה אוטומטית מטא־נתונים של הופעות וחפיפות. הניסוי המחושב מראש מתבטל לאחר בנייה חדשה כדי למנוע הצגת תוצאות ישנות. לחישובו מחדש, אם מותקן Node 18 ומעלה:

```
node tools/run_experiments.cjs
```

לניסוי מותאם אפשר להעביר `--query=/absolute/path/query.json` ו־`--output=/absolute/path/report.json.gz`. מבנה ההגדרות מופיע בתחילת הסקריפט; הניסוי מקבל מזהי יחידות, לא שאילתת מילים חופשית. אין צורך ב־Node לשימוש באפליקציה או לפרסומה. אין להעלות לאתר קובצי מקור, ארכיוני ZIP או מסד .build.
